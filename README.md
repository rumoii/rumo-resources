## 使用与反馈

先阅读对应资源的说明，再选择适合自己环境的版本。文件名及适用版本以各次发布为准，旧版本继续保留。

资源问题或失效链接可以通过 [Issues](https://github.com/rumoii/rumo-resources/issues) 反馈。请勿上传账号密码、私钥或节点凭据。

各资源的授权以其自身说明和随附许可证为准，第三方文件保留原作者与许可证。新增资源见[发布约定](PUBLISHING.md)。
